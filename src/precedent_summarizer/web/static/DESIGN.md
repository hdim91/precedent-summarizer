# CASEBOOK · 디지털 판례집 / 리서치 워크벤치

판결의 권위는 세리프 원문과 표제에서, 탐색의 속도는 산세리프 UI와 정돈된 표에서 표현한다. 네이비 정보 체계와 따뜻한 종이색 원문을 분리하고 버건디는 검색·활성·근거 연결에만 사용한다.

의미 배지는 `--ok-*`(기각·검증 통과), `--reverse-*`(파기·인용), `--final-*`(파기자판), `--neutral-*`(각하·기타), `--sonnet-*`, `--opus-*`의 bg/ink 쌍을 사용한다. 각하는 외곽선, 검증은 통과/미통과 문자와 기호를 함께 표시한다. 색만으로 의미를 전달하지 않는다. 다크는 따뜻한 올리브 원문과 푸른 작업 공간을 별도 설계한다.

## 글꼴·크기

- `--font-ui`: Pretendard → Apple/Windows 시스템 산세리프 → Malgun Gothic → sans-serif.
- `--font-record`: Noto Serif KR → Nanum Myeongjo → Batang → Times New Roman → serif.
- 설치된 권장 글꼴을 우선 사용한다. 원격 폰트/CDN 요청은 없으며 미설치 환경에서는 시스템 대체 글꼴로 표시한다.
- `--t-label` 11px / `--t-note` 13px / `--t-body` 15px / `--t-section` 18px / `--t-lead` 22px / `--t-title` 30.4~44px.
- 원문 16px·줄간격 2.0·최대 45ic, 요약 15px·줄간격 1.9. 라벨 자간 0.12~0.16em. 숫자·날짜·사건번호는 tabular-nums.
- 원문 텍스트에는 공백·줄바꿈 삽입이나 HTML 재해석을 하지 않는다.

## 간격·반경·그림자

- `--s1` 4px(미세 간격), `--s2` 8px, `--s3` 16px, `--s4` 24px, `--s5` 32px, `--s6` 48px, `--s7` 64px.
- `--r1` 4px(버튼·표·원문·법원 카드), `--r2` 8px(검색 작업 영역).
- `--shadow-1`: 0 2px 8px / `--shadow-2`: 0 8px 24px. 통계·독서 카드와 검색 영역에만 사용.
- 포커스는 accent 2px, 오프셋 4px.

## 화면·상호작용

- 목록: 표제 → 통계 카드 → 넓은 검색 바 → 접이식 필터 → 헤어라인 표. 사건명을 강조하고 한 줄 요약은 최대 두 줄로 제한한다.
- 상세: 사건번호·세리프 사건명·메타·결론 배지 표제. 왼쪽 요약과 오른쪽 sticky 원문. 검증은 작은 인장 배지 묶음으로 표시한다.
- 근거: API 전체 순서로 ①~⑳(이후 숫자) 번호 칩. 원문 옆 미니맵은 유효한 start / 전체 코드포인트 수 × 100으로 배치한다. null/범위 밖 오프셋은 점을 만들지 않는다. 중복 위치는 서로 다른 버튼으로 남겨 키보드로도 접근 가능하다.
- 탭 전환 시 미니맵·활성 강조를 즉시 비워 이전 버전 근거를 선택할 수 없게 한다. 근거 클릭은 200ms 감속 강조 효과와 원문 이동을 사용한다.
- 로딩은 스켈레톤, 빈 결과는 조건 변경 안내, 오류는 다시 불러오기 버튼. `prefers-reduced-motion`에서는 강조·로딩 애니메이션과 smooth scroll을 사용하지 않는다.
- 900px 이하: 요약/원문 세로 배치·sticky 해제. 600px 이하: 표를 사건명 중심 카드 목록으로 전환하고 셀 라벨을 표시한다.
- 인쇄: 요약 다음 페이지에 원문, 고정·스크롤 높이 해제, 배경·그림자·탐색 컨트롤 제거, 근거 번호 유지.

텍스트 색상 쌍의 상대 휘도 검사: 라이트 최소 5.15:1, 다크 최소 6.18:1(본문/보조 정보/원문/강조/의미 배지). 선택한 쌍은 일반 텍스트 AA 기준 4.5:1 이상이다.

## 검토 범위

기능 회귀는 TestClient와 Node 테스트로 검사한다. 실제 OS 글꼴·행간·미니맵 위치·모바일·다크·인쇄 미리보기는 사용자 PC 스크린샷 검토가 필요하다.
