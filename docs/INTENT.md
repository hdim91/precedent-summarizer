# INTENT — 이 프로젝트가 존재하는 이유

> 목적·범위가 바뀔 때만 수정한다. 마지막 수정: 2026-10-23 18:38 KST

## 한 줄 정의
국가법령정보센터에 수록된 **대법원 판례**를 배치로 수집·요약해 두고, 내부 연구자가 웹에서 검색·열람하는 도구.

## 사용자와 용도
- 내부 연구용(본인 및 공동연구 변호사). 외부 공개 서비스가 아니다.
- 법률 자문 도구가 아니다 — 판례 요약·검색까지가 범위.

## 범위
- 포함: 대법원 판례(law.go.kr Open API `target=prec`), 배치 요약, 근거 문장 연결, 웹 검색·상세 조회
- 당분간 제외: 하급심, 헌법재판소, 실시간(요청 시점) 요약, 외부 공개·다중 사용자 인증

## 핵심 설계 원칙
1. **근거 기반 요약**: 요약의 모든 항목은 원문 문장으로 역추적 가능해야 한다.
2. **원문 보존**: raw 응답은 불변, 요약은 언제든 재생성 가능.
3. **정직한 빈 값**: API가 주지 않은 정보는 만들지 않는다.
4. **재사용**: 기존 리걸테크 코드 자산(`LawGoKrClient` 등)을 확장한다.
5. **비용 통제**: 전체 배치 전 시범 실측 → 예상 비용 보고 → 승인 후 실행.
6. **비밀정보 보호**: `docs/RULES.md` 1장.

## 성공 기준 (초안)
- 수집: API 총 건수 대비 수집 누락 0, 필드 누락 리포트 존재
- 요약: 자동 검증기(근거 존재·주문 일치·참조조문 대조) 통과율 측정 및 공개, 변호사 표본 검토 통과
- 웹: 목록·검색·상세(요약↔원문 근거 하이라이트) 동작

## 아키텍처 개요
law.go.kr → 수집(raw 캐시) → 정제·적재(SQLite+FTS5) → 요약 엔진(Claude Batch API) → 검증기 → summaries → 웹 UI

## 단계
P0 환경 → P1 수집 → P2 정제·적재 → P3 요약 엔진(시범 50건) → P4 배치 파이프라인 → P5 웹 UI → P6 독립 검증
(각 단계의 담당·통과 조건은 `docs/STATE.md`와 `docs/DECISIONS.md` 참조)
