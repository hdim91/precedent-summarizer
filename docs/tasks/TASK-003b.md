## 디자인 브리프
### 1. 콘셉트
- "디지털 판례집 + 리서치 워크벤치". 신뢰감(권위·정확성)과 현대적 세련됨(절제된 여백·정교한 타이포그래피)의 결합.
- 피할 것: 기본 브라우저 스타일 느낌, 평평한 회색 일색, 과한 그라데이션·그림자·아이콘 남용, 장식용 일러스트.

### 2. 타이포그래피 (가장 중요)
- **UI·요약**: 산세리프(권장 Pretendard). **판결 원문**: 세리프(권장 Noto Serif KR) — 판례집 같은 독서 경험.
- 명확한 위계: 디스플레이(페이지 제목) / 섹션 제목 / 본문 / 보조 정보 / 라벨(소문자 대신 자간 넓힌 작은 대문자형 라벨, 예: `CASE`, `HOLDING`) 최소 5단계, 모듈러 스케일 사용.
- 원문 가독성: 한 줄 40~45자 내외, 줄간격 1.8 이상, 문단 간격 확보. 날짜·사건번호·건수는 고정폭 숫자(`font-variant-numeric: tabular-nums`).
- 폰트는 CDN 허용(버전 고정, 각 1개 출처): Pretendard(jsdelivr), Noto Serif KR(Google Fonts). 로딩 실패 시 시스템 폰트로 자연스럽게 대체.

### 3. 색 체계
- 디자인 토큰(CSS 변수)으로 정의, 라이트/다크 모두 설계(다크는 단순 반전 금지).
- 권장 팔레트: 잉크 네이비(본문·헤더), 따뜻한 종이색 배경(원문 패널), 절제된 강조색 1개(예: 버건디 또는 브라스) — 강조색은 근거 하이라이트·주요 버튼·활성 상태에만.
- 의미 색(배지): 결론 유형(상고기각/파기환송/파기자판/각하 등) 구분, 모델(Sonnet/Opus), 검증(통과/미통과), 본문 미제공. 색만으로 구분하지 말고 텍스트·형태 병행. WCAG AA 대비.

### 4. 화면별 요구
- **목록**: 상단 헤더(브랜드 워드마크 + 내부용 표시), 검색을 화면의 중심 요소로(넓은 커맨드 바 스타일), 필터는 정돈된 한 줄/접이식 패널, 통계는 숫자가 돋보이는 절제된 카드. 표는 헤어라인 구분선·충분한 행 높이·행 hover, 사건명 강조, 한 줄 요약은 2줄 말줄임.
- **상세**: 상단 사건 헤더(사건번호·사건명·법원·선고일·결론 배지)를 판례집 표제처럼. 좌 요약 / 우 원문.
  - 원문 패널은 스크롤 시 고정(sticky), 구획 목차는 원문 패널 상단의 탭/칩.
  - 근거 표시는 번호 칩(①②…) 스타일, 클릭 시 원문 하이라이트가 부드럽게 나타나고(감속 애니메이션 150~250ms) 위치로 스크롤.
  - **원문 미니맵**: 원문 패널 옆 얇은 세로 레일에 현재 요약 버전의 모든 근거 위치를 점으로 표시(클릭 시 이동). 요약과 원문의 대응이 한눈에 보이게.
  - 검증 결과는 "검증 인장"처럼 작은 배지 묶음(인용 n/n, 주문 대조, 모델).
  - 법원 작성 원문(판시사항·판결요지 등)은 다른 배경 톤의 접이식 카드, "법원 작성" 라벨 명확히.
- **상태 화면**: 로딩은 스켈레톤, 빈 결과·오류는 안내 문구+다음 행동 제시.
- **인쇄**: 상세 화면 인쇄용 스타일(요약 → 원문 순, 배경색 제거, 근거 번호 유지).

### 5. 마감 품질
- 8px 기반 간격 체계, 일관된 모서리 반경(작게), 그림자는 1~2단계만.
- 포커스 링을 디자인 요소로(강조색, 2px), 키보드 사용 그대로 유지. `prefers-reduced-motion` 시 애니메이션 제거.
- 반응형: ≤900px 세로 배치, ≤600px 표를 카드 목록으로 전환.
