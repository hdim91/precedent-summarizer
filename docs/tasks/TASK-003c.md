2. **요약 없는 판례의 좌측 패널**: 지금은 "요약 없음" 한 줄만 있어 좌측이 비어 보인다(사용자 화면). → 요약이 없으면 좌측 패널에 **법원 작성 판시사항·판결요지**를 "법원 작성 요지 · 자동 요약 아님" 라벨과 함께 기본 표시하고, 하단 접이식 '법원 작성 원문' 영역과 중복되지 않게 처리. 둘 다 없으면 "요약 대기 중 — 원문을 확인하세요" 상태 카드.
3. **목록 첫 화면 밀도**: 1440×960에서 표제·통계·검색 패널이 첫 화면을 다 차지해 판례 목록이 보이지 않는다. 연구 도구이므로 첫 화면에 **목록 최소 5행**이 보이도록:

   - 필터는 기본 접힘(활성 필터가 있으면 펼침 + 활성 필터 칩 표시)
4. **결론 배지 위치**: 상세 상단 사건 표제 옆에 결론 유형 배지(요약이 있을 때, 선택된 버전 기준)를 표시 — TASK-003b 브리프 항목인데 현재 상단에 없음.
