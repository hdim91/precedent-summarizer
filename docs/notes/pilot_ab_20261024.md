# Sonnet 5.5 vs Opus 5.5 요약 비교 시험 (2026-10-24 06:40~07:05 KST)

## 설계
- 대상: 대법원 출처·판결요지 있는 판결. 2024~2026년 일반 20건(본문 길이 분위 균등), 장문(>15,000자) 5건, "전원합의체 판결을 인용한" 일반 판결 5건(※ 당초 전합 표본으로 뽑았으나 선정 오류 — 실제 전합 아님), **실제 전원합의체**(다수·반대의견 존재, 2016~) 5건. 총 35건.
- 입력: 판례내용만(블라인드, D-019). 프롬프트·스키마 v1 동일. 표준 API(비배치) 호출.
- 채점: 법원 작성 판시사항·판결요지를 기준으로 두 요약을 X/Y 무작위 순서로 쌍대 채점. 심판 2종(Sonnet 5.5, Opus 5.5)으로 자기선호 편향 점검.
- 산출물: `data/pilot/ab_sonnet/`, `ab_opus/`, `eval_judge_sonnet/`, `eval_judge_opus/` (git 제외)

## 한계
